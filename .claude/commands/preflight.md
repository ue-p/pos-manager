---
description: 学祭本番前の最終チェック（リハーサル前・前日に実行）
---

学祭本番に向けた最終チェックを行ってください。デプロイは行わず、確認と報告だけをします。

自動で確認すること：
1. `npm run lint && npm run typecheck && npm run test && npm run test:rules && npm run build` がすべて通るか。
2. `firestore.rules` が D-16 のとおりか（共通アカウント以外拒否、transactions の削除・上書き禁止、display_state のみ公開読み取り）。
3. 本番ビルドが Emulator ではなく本番プロジェクトに接続する設定になっているか（`.env` の扱い、Emulator 接続が dev 限定か）。
4. `settings` の既定値（価格・初期在庫・目標額 40,750円・test_mode=false）。
5. `docs/requirements.md` 8.2 の未決事項のうち、実装に影響するものが残っていないか。

ユーザー向けに、人が手で行う当日チェックリストを `docs/operations.md` に作成または更新する。最低限：
- 開店前：全端末でログイン、端末の時刻確認、レジ番号の確認、テストモードの帯が消えていること、お客さん用画面の表示、在庫数の確認
- 営業中：30分ごとのCSVエクスポートと共有ドライブへの保存、残りわずかの絵柄は口頭確認
- Wi-Fi が切れたとき：入力は続けてよい、未送信件数が0に戻るまでブラウザを閉じない
- 閉店時：未送信件数0の確認、CSVエクスポート、レジ締め、差額があれば施策ログ

最後に、問題点と対処案を重要度順に報告してください。
