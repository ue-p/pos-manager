# 当日の運用手順書

学祭当日、レジに立つ部員と運営担当が使う手順です。迷ったら「会計は止めない」「分からない客層は不明」が原則です。

## 開店前チェック（各日）

- [ ] 全端末でアプリを開き、ログインできている（初回だけ通信が必要。以後はオフラインでも開ける）
- [ ] **端末の時刻が正しい**（数分ずれていると時間帯別の分析が狂う）
- [ ] 各端末の「設定・出力」→「この端末」でレジ番号が正しい（レジごとに別の番号）
- [ ] **テストモードの紫の帯が、全端末で消えている**（オフラインの端末には切替が届かないので必ず目視）
- [ ] お客さん用画面が表示されている
  - 同じPCの2画面目：「設定・出力」→「この端末で開く」→ 外部モニターへ移動 →「全画面」
  - 別端末（タブレット等）：「設定・出力」に出ているURL（`/display?reg=reg_1` など）を開く（ログイン不要）
- [ ] レジ画面の在庫数が実物と合っている（違えば「設定・出力」→「価格・在庫」の初期在庫を直す）
- [ ] 価格が正しい（変更すると、それ以降の会計から新しい価格になる。過去の会計は変わらない）
- [ ] 状態バーが「オンライン」「未送信 0件」
- [ ] **エクスポート担当の端末**（1台）と **VR係の端末**（1台）が決まっている
- [ ] エクスポート担当のPCで、Chrome のダウンロード先が共有フォルダの同期先になっている（下の「CSVの保存（エクスポート担当）」）

## 担当の分け方

| 担当 | 台数 | やること |
| --- | --- | --- |
| レジ | レジの数だけ | 会計の入力 |
| エクスポート担当 | 1台 | 30分ごと・閉店時のCSVエクスポートと共有フォルダへの保存 |
| VR係 | 1台 | VR体験の記録（「＋1人」）と、その取消 |

1台が複数の担当を兼ねてもよい（例：レジ1のPCがエクスポート担当も兼ねる）。

## 会計の流れ（すべてタップ）

1. 商品ボタン（押した回数が個数。カートの −／＋ で調整）
2. 客層（子連れ／学生／大人／その他／**分からなければ不明**）
3. 人数（1〜4人／5人以上）
4. 預かり金（ちょうど／500／1,000／5,000／10,000。複数回押すと加算。間違えたらクリア）
5. 「会計確定」→ お釣りが大きく出る。次の商品ボタンで次の会計へ

- 押し間違えたら、その場で **「直前の取消」** → 入力し直す
- もっと前の会計を取り消すときは「会計一覧」から選ぶ（確認あり。取消は元に戻せない）
## VR体験の記録（VR係）

- VR体験の記録は **VR係の端末1台だけ** で行う。VR体験をした人がいたら、1人ごとに「＋1人」
- 押し間違えたら、**同じ VR係の端末で**「取消」を押す（取消できるのは、その端末で最後に記録した1件。他の端末からは取り消せない）
- **テストモードをオフにすると、VR体験の人数の表示が本番の人数に切り替わる**（テストモード中はテストの記録だけ、オフにすると本番の記録だけを数える）。練習で押した人数が消えたように見えるが、正常

## 営業中

- **30分ごとにCSVをエクスポート**（エクスポート担当。状態バーの「CSV保存」が黄色になったら合図）
  - 「CSV保存」の経過時間は**全端末で共通**。どの端末でも、エクスポート担当が最後に保存してからの時間が出る
  - 手順は下の「CSVの保存（エクスポート担当）」
- 「残りわずか」（黄色）の絵柄は、他のレジと口頭で残数を確認する（オフライン中は他端末の販売が反映されないため）
- 店頭で何か変えたら施策ログに記録する（「設定・出力」→「施策ログ」。プリセットボタンか自由メモ）

## Wi-Fi が切れたとき

- **入力はそのまま続けてよい**。会計は端末に保存され、復帰後に自動で送信される
- 状態バーの「未送信 ◯件」が 0 に戻るまで、**ブラウザを閉じない・ログアウトしない・閲覧データを消さない**
- 同じPCのお客さん用画面はオフラインでも動く。別端末のお客さん用画面は復帰まで止まる（会計には影響しない）
- PCが壊れたら：別の端末でログインし、レジ番号を合わせれば続きから入力できる（未送信だった分は壊れたPCの中に残る）

## 閉店時（各日）

1. 全端末で「オンライン」「未送信 0件」を確認
2. エクスポート担当がCSVをエクスポートして共有フォルダに保存
3. レジ締め（「設定・出力」→「レジ締め」）
   - レジごとに、数えた現金の**総額**（釣銭準備金を含む）を入力して記録
   - 差額が出たら、施策ログに理由を書く（例：「お釣りの渡し間違い 100円」）
4. 全端末で「未送信 0件」を確認してから、エクスポート担当が最後にもう一度エクスポートして保存（レジ締めの記録を含めるため）

## CSVの保存（エクスポート担当）

**保存先は1か所だけ**：DA研アカウントの Google ドライブ
「マイドライブ\2026_経営陣\07_商大祭\99_POSデータ保存場所」

ZIP のファイル名は `pos_export_reg_1_20261103_143005.zip` のように、レジ番号と日時（秒まで）が入る。
中身は全レジ分なので、エクスポートは担当の1台だけでよい。

### エクスポートするとき（毎回）

1. 状態バーが **「オンライン」かつ「未送信 0件」** であることを確認する
   - オフラインや未送信があるときは出さない（他の端末の分が入らない、不完全な ZIP になる）。設定画面にも注意が出る
2. 「設定・出力」→「CSVをダウンロード（ZIP）」
3. 共有フォルダに ZIP が入ったことを確認する（下の準備をしたPCなら自動で入る）
   - エクスポートすると施策ログに「CSVをエクスポートした（ファイル名）」が自動で記録され、全端末の「CSV保存」が「1分以内」に戻る

### 事前準備（エクスポート担当のPC。学祭前に1回）

1. 「パソコン版 Google ドライブ」（Google Drive for desktop）をインストールし、**DA研アカウント**でログインする
2. エクスプローラーに Google ドライブのドライブ（例：`G:`）ができるので、次のフォルダが見えることを確認する
   `G:\マイドライブ\2026_経営陣\07_商大祭\99_POSデータ保存場所`
   （**ドライブ文字は環境によって異なる**。`G:` でなければ、エクスプローラーの「PC」に出ている Google Drive のドライブ文字に読み替える）
3. Chrome の右上「︙」→「設定」→「ダウンロード」を開く
4. 「保存先」の「変更」を押し、上のフォルダを選ぶ
5. 「ダウンロード前に各ファイルの保存場所を確認する」は**オフ**にしておく（毎回フォルダを選ぶ手間と、選び間違いを防ぐ）
6. テストモード中に一度エクスポートし、ZIP がそのフォルダに入り、Google ドライブ（ブラウザ版）にも同期されることを確認する

### PCが使えないとき（タブレット・スマホから手動でアップロード）

1. タブレット・スマホでアプリにログインし、状態バーが「オンライン」「未送信 0件」であることを確認する
2. 「設定・出力」→「CSVをダウンロード（ZIP）」
   - iPhone / iPad（Safari）：ダウンロードした ZIP は「ファイル」アプリの「ダウンロード」に入る
   - Android（Chrome）：「ファイル」アプリ（または「ダウンロード」）に入る
3. 「Google ドライブ」アプリを開き、**DA研アカウント**に切り替える（右上のアカウントアイコン）
4. 「マイドライブ」→「2026_経営陣」→「07_商大祭」→「99_POSデータ保存場所」を開く
5. 「＋」→「アップロード」→ ダウンロードした ZIP（`pos_export_reg_…zip`）を選ぶ
6. フォルダに ZIP が表示されたことを確認する
   - ZIP を展開（解凍）せず、そのままアップロードする

## 分析するとき

- 共有フォルダの**いちばん新しい ZIP**（ファイル名の日時が最新のもの）を使う。中身は全レジ分
- ZIP の中身：`sales_lines.csv` / `transactions.csv` / `vr_visits.csv` / `action_logs.csv` / `register_closings.csv`
- 取消・テストの行も入っている。集計では `is_void == False and is_test == False` で絞る
- `action_logs.csv` の `log_type` が `csv_export` の行はエクスポートの記録（施策ではない）。施策の前後比較では `log_type == "manual"` で絞る
- 中身の検査：`python scripts/check_csv.py pos_export_reg_1_YYYYMMDD_HHmmss.zip`

```python
import pandas as pd
lines = pd.read_csv("sales_lines.csv")
valid = lines[~lines.is_void & ~lines.is_test].copy()
valid["timestamp"] = pd.to_datetime(valid["timestamp"])
valid.groupby(valid.timestamp.dt.hour)["amount"].sum()
```
